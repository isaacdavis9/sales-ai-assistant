# AI Sales Meeting Assistant

An AI-powered sales productivity application built with Python, Streamlit, SQLite, and the OpenAI API.

## Features

- Upload customer meeting transcripts
- AI-generated meeting summaries
- Customer pain point extraction
- Buying signal detection
- Opportunity scoring
- AI-generated follow-up emails
- AI-generated sales tasks
- Dashboard for meeting analytics
- SQLite database storage

## Technologies

- Python
- Streamlit
- OpenAI API
- SQLite
- JSON

## Installation

```bash
git clone https://github.com/isaacdavis9/sales_ai_assistant.git

cd sales_ai_assistant

pip install -r requirements.txt

streamlit run app.py
```
## Environment Variables

Create a `.env` file:

```text
OPENAI_API_KEY=your_api_key_here
```
